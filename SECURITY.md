# Security Policy

## Reporting a vulnerability

Please report security problems **privately**. Do not open a public issue, pull request or discussion about them.

1. Open this repository's **Security** tab and choose **Report a vulnerability**.
2. Describe what is affected (a page or an API route), the steps to reproduce it, and the impact you observed.

You will receive a reply once the report has been reviewed. Please allow reasonable time for a fix before you disclose the problem publicly.

## Scope

- The live shop at [www.nandanatextile.lk](https://www.nandanatextile.lk) and its API.
- The code in this repository.

## While testing, please do not

- access, change or delete other people's data; use only accounts you own;
- make payments or place orders you do not intend to complete;
- run denial-of-service attacks, spam, or automated scans that slow the service down;
- use social engineering or phishing against the shop's staff or customers.

## Supported versions

Only the current `main` branch, which is what the live shop runs, receives security fixes.
